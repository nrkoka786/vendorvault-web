# vendorvault-web
Official landing page, Privacy Policy, and Terms of Service for VendorVault – The AI Contract Renewal Sentinel for Google Workspace.

VendorVault.app Website

This repository hosts the public-facing landing page for VendorVault, a Google Workspace Add-on that helps businesses track contract renewals and subscriptions.

Live Site: https://vendorvault.app

Purpose

This static website serves two critical functions:

Marketing: Explains the value proposition to potential users.

Compliance: Hosts the Privacy Policy and Terms of Service required by Google for OAuth verification.

Tech Stack

HTML5: Single-file architecture for speed and simplicity.

Tailwind CSS: Used via CDN for rapid styling.

Font Awesome: For icons.

Vercel: Hosting and SSL termination.

Deployment

This repository is connected to Vercel.

Push to main: Triggers an automatic production deployment.

Project Structure

index.html: The main landing page containing the Hero section, Features, and Compliance Modals.

robots.txt: (Optional) SEO instructions for web crawlers.
